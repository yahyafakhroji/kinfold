The dashboard is rebuilt. Overview says whether Kinfold is working and what it saved this week, and lists what needs you: failing summaries, an old backup, a release ready to install, or a hub that cannot be reached. Sessions, Memory and Activity are tables sorted, filtered and paged on the daemon; a row opens in a side panel, and the address keeps the page, the filters and the open row. Memory can be sorted by how often each memory was recalled. Activity lists recalls, saved memories, summaries and why they failed, backups, restores, updates, sign-ins and devices joining, kept for 90 days; the daemon log is a download there. Impact shows tokens saved two ways, never added together: measured by the impact test (including "No measurable saving yet" when the difference is within normal variation, and the cost when memory adds tokens), or an "up to" estimate where nothing is measured yet. Settings groups agents and summaries, search, updates, central memory, data and retention, and privacy, and says what each setting does. The dashboard has a dark mode that follows the system. The store moves to schema 18, which records each session's device, each memory's recall count and the summary run that wrote it; records from before the upgrade say they were not recorded.
