More observer providers. API providers with your own key: `anthropic-api`, `openai-api`, `gemini-api`, `qwen-api` (DashScope) and `openai-compatible` for any OpenAI-style server, including Ollama and LM Studio on this machine with no key. `goose-cli` runs the observer through a provider key you gave Goose, after the same planted-instruction safety check as Codex and OpenCode. Setup says why an agent's own CLI cannot run its summaries, lists Auggie, which cannot be picked until a live run proves it safe, and takes `--observer-endpoint <url>` for the endpoint providers. The dashboard Models page offers every provider with its key entry and address.
